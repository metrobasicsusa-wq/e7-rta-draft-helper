# RTA 选人助手

用 Smilegate 官方对局记录接口的高段位 RTA 数据，给第七史诗选人阶段出建议：下一手选谁、对方可能选谁、选完后 Ban 谁。

接口格式、算法、参数取舍和已知局限都写在 [DESIGN.md](DESIGN.md)。

## 文件

| 文件 | 作用 |
|---|---|
| `crawl.py` | 从一个玩家开始，抓他最近 100 场对局，再顺着对手往高段位找，存进 `e7.db` |
| `stats.py` | 从 `e7.db` 算角色胜率、搭配、克制，生成 `stats.json` 和 `draft.html` |
| `template.html` | 页面模板，`stats.py` 把数据填进去 |
| `draft.html` | 生成好的页面，直接用浏览器打开就能用 |

## 更新数据

只需要 Python 3，不用装别的包。

```bash
python crawl.py --max-players 400
python stats.py
```

- 抓取每次调用之间默认等 1.2 秒，400 个玩家大约 15 分钟。别把间隔调得太短。
- 12 小时内抓过的玩家会跳过，所以可以随时中断再继续。
- `--seed 你的编号:world_global` 可以从你自己的账号开始抓。编号在官方对局记录网站的网址里。
- `python stats.py --min-grade warlord` 只统计双方都在 Warlord 段以上的对局。

## 估计胜率怎么算

角色本身的胜率，加上和己方每个角色的搭配修正，再加上对敌方每个角色的克制修正，都在对数几率上相加。场次少的角色和组合会被拉回平均值，推荐里只考虑至少 100 场的角色。

这是粗略参考：看不到配装和练度，而且样本是高段位玩家的最近对局，不是全服数据。
